# Перенос художественного стиля на мобильном устройстве

## Цель проекта

Цель проекта — разработать Android-приложение для произвольного переноса художественного стиля на фотографию пользователя.

Пользователь может сделать фотографию камерой смартфона или выбрать её из Галереи, затем выбрать художественный стиль и получить стилизованное изображение. Обработка выполняется локально на мобильном устройстве.

В проекте используется предобученная модель **Magenta Arbitrary Image Stylization**, подготовленная для запуска на мобильных устройствах в формате TensorFlow Lite.

Использование готовой mobile-ready модели соответствует рекомендации задания использовать предобученные сети, которые гарантированно работают на мобильном устройстве.

## Архитектура решения

```text
Подготовка стилевых изображений

WikiArt dataset
        ↓
Проверка валидности изображений
        ↓
Отбор изображений-стилей
        ↓
data/style_images/
        ↓
Встроенные стили Android-приложения
        ↓
app/src/main/assets/styles/


Мобильный inference

Камера / Галерея
        ↓
Контентное изображение
        +
Стиль из Галереи / встроенный стиль WikiArt
        ↓
style_predict.tflite
        ↓
Style embedding
        +
Контентное изображение
        ↓
style_transform.tflite
        ↓
Стилизованное изображение
        ↓
Сохранение в Галерею Android-устройства
```

## Реализованный мобильный прототип

Приложение реализовано на Kotlin в Android Studio и протестировано на физическом Android-устройстве Samsung.

### Функциональность

- Получение контентного изображения через системную камеру Android.
- Выбор контентного изображения из Галереи.
- Выбор изображения-стиля из Галереи.
- Выбор встроенного набора художественных стилей WikiArt.
- Отображение встроенных стилей в горизонтальной ленте миниатюр.
- Предпросмотр исходной фотографии и выбранного изображения-стиля.
- Локальный inference TensorFlow Lite.
- Индикатор процесса обработки изображения.
- Отображение стилизованного результата.
- Сохранение результата в JPEG-формате в медиатеку телефона.
- Отсутствие передачи пользовательских фотографий на внешний сервер.

### Использование приложения

1. Нажать **«Сделать фото камерой»** или **«Выбрать фотографию из галереи»**.
2. Сделать или выбрать исходное контентное изображение.
3. Выбрать стиль:
   - через кнопку **«Выбрать стиль из галереи»**;
   - либо нажать на одну из встроенных миниатюр WikiArt.
4. Нажать **«Применить стиль»**.
5. Дождаться завершения локального inference.
6. Просмотреть результат в блоке **«Результат»**.
7. Нажать **«Сохранить результат»**.

Готовые изображения сохраняются в:

```text
Pictures/StyleTransferApp
```

## Используемая модель

В мобильном приложении используется предобученная модель **Magenta Arbitrary Image Stylization** в формате TensorFlow Lite.

Модель состоит из двух связанных частей:

| Модель | Назначение |
|---|---|
| `style_predict.tflite` | Получает изображение-стиль и формирует вектор стиля — style embedding |
| `style_transform.tflite` | Получает контентное изображение и style embedding, затем создаёт стилизованный результат |

Модели размещены в Android-проекте:

```text
app/src/main/assets/
├── style_predict.tflite
└── style_transform.tflite
```

Модель выполняется локально через TensorFlow Lite Interpreter.

### Подготовка изображений

Перед inference приложение подготавливает изображения:

- изображение-стиль приводится к размеру 256 × 256 пикселей;
- контентное изображение приводится к размеру 384 × 384 пикселей;
- изображения преобразуются в RGB-тензоры;
- параметры квантизации считываются непосредственно из TFLite-тензоров;
- приложение поддерживает значения TensorFlow Lite типов `FLOAT32`, `INT8` и `UINT8`.

## Встроенные стили WikiArt

Для стилевых изображений используется набор WikiArt.

В ноутбуке выполнены:

- поиск изображений в локальной папке WikiArt;
- проверка валидности файлов;
- отбор набора стилевых изображений;
- копирование выбранных стилей в `data/style_images`;
- inference Magenta на собственных парах изображений;
- сохранение результатов в `results/`.

В ходе проверки набора данных найдено и проверено:

```text
71 446 валидных изображений WikiArt
```

Для мобильного приложения был отобран набор из 30 изображений-стилей.

Исходные отобранные стили находятся в:

```text
data/style_images/
```

Встроенные стили, добавленные в APK, находятся в:

```text
app/src/main/assets/styles/
```

В приложении они загружаются через `AssetManager` и отображаются как горизонтальная лента миниатюр.

## Ноутбук экспериментов

Ноутбук расположен по пути:

```text
training/style_transfer_wikiart.ipynb
```

Он используется для подготовки стилевых изображений WikiArt и проверки inference предобученной модели Magenta через TensorFlow Hub.

В ноутбуке выполняются следующие этапы:

1. Настройка путей проекта.
2. Поиск изображений WikiArt.
3. Проверка файлов и исключение повреждённых изображений.
4. Создание CSV-индекса валидных изображений.
5. Случайный отбор стилевых изображений.
6. Копирование выбранных стилей в `data/style_images`.
7. Загрузка контентного изображения.
8. Загрузка предобученной Magenta-модели через TensorFlow Hub.
9. Запуск переноса стиля.
10. Сохранение результата в `results/`.

Используемая baseline-модель TensorFlow Hub:

```text
[https://tfhub.dev/google/magenta/arbitrary-image-stylization-v1-256/2](https://tfhub.dev/google/magenta/arbitrary-image-stylization-v1-256/2)
```

> В ноутбуке используется предобученная модель Magenta для проверки и экспериментов. Данные WikiArt применяются как изображения художественных стилей, а не как доказательство самостоятельного полного обучения модели с нуля.

## Камера

В приложении реализована кнопка:

```text
Сделать фото камерой
```

Она запускает системное приложение камеры Android. После подтверждения кадр возвращается в приложение и автоматически используется как контентное изображение.

Для безопасной передачи URI фотографии между приложением и системной камерой применяется `FileProvider`.

Временный снимок создаётся в cache-каталоге приложения, а готовое стилизованное изображение сохраняется через `MediaStore`.

## Сохранение результата

Результат переноса стиля сохраняется в формате JPEG через `MediaStore`.

Путь сохранения:

```text
Pictures/StyleTransferApp
```

Это позволяет открыть созданное изображение в стандартной Галерее Android-устройства.

## Запуск приложения

### Требования

- Android Studio;
- Android SDK;
- подключённое Android-устройство с включённой USB Debugging;
- либо настроенный Android Emulator;
- интернет-соединение для первой Gradle-синхронизации и скачивания зависимостей.

### Инструкция запуска

1. Открыть проект в Android Studio.
2. Дождаться завершения Gradle Sync.
3. Подключить Android-устройство через USB.
4. Подтвердить запрос USB Debugging на устройстве.
5. Выбрать устройство в верхней панели Android Studio.
6. Нажать кнопку **Run** .
7. После установки приложение откроется на устройстве.
