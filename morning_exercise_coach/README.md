# Virtual Morning Exercise Coach

Компьютерное зрение для автоматической оценки техники выполнения физических упражнений (утренней зарядки) по эталонному видео.

---

## 1. Цель и бизнес-контекст проекта

- **Цель:** разработка системы оценки сходства движений пользователя с эталоном с помощью извлечения ключевых точек тела (Pose Estimation), временной синхронизации, пространственной нормализации и расчёта метрик сходства в динамике.
- **Практическая ценность:** автоматизация контроля техники тренировок в мобильных и веб-сервисах без участия тренера, повышение вовлечённости и удержания пользователей (Retention), предотвращение травм при неправильном выполнении.
- **Целевые технические метрики:**
  - Косинусное сходство векторов поз ($Cosine\ Similarity \in [-1, 1]$, пересчитанное в шкалу $0\text{--}100\%$).
  - Взвешенное расстояние между ключевыми точками ($Weighted\ Distance$) с учётом достоверности ($confidence$).

---

## 2. Архитектура пайплайна

```text
Видео пользователя (original) + Эталон (reference)
                        ↓
Извлечение 33 ключевых точек через MediaPipe Pose Landmarker
                        ↓
Временная синхронизация (алгоритм нормализованного времени)
                        ↓
Пространственная нормализация поз (центрирование, масштабирование)
                        ↓
Расчёт покадровых метрик сходства и расстояния
                        ↓
Генерация результатов (видео со скелетом и инфопанелью, CSV, графики)
```

---

## 3. Входные данные и структура признаков

- `data/reference/` — эталонное видео с правильной техникой упражнения (`.mp4`).
- `data/original/` — видеозапись тренировки пользователя (`.mp4`).
- `data/processed/` — промежуточные извлечённые тензоры:
  - `poses.npy` — координаты ключевых точек размерности `[N, 33, 2]`, где $N$ — число кадров, 33 — landmark-точки тела, 2 — координаты $(x, y)$, нормированные на размер кадра.
  - `conf.npy` — оценки достоверности детекции точек размерности `[N, 33]`, $c_i \in [0, 1]$.

---

## 4. Трансформации данных

1. **Временное выравнивание (`temporal_alignment`):** сопоставление разнодлительных видеопотоков с различной частотой кадров (FPS) по нормализованной временной шкале $t \in [0, 1]$ с сохранением фазовой структуры движения.
2. **Пространственная нормализация (`posenormalizer`):**
   - Перенос начала координат в центр таза человека.
   - Масштабирование по расстоянию между ключевыми антропометрическими точками для нивелирования разницы в росте и удаленности от камеры.
   - Аффинные преобразования координат для корректного сопоставления ракурсов.

---

## 5. Метрики и математическая модель

- **Косинусное сходство:**
  $$\text{Cosine Similarity} = \frac{\mathbf{u} \cdot \mathbf{v}}{\|\mathbf{u}\|_2 \cdot \|\mathbf{v}\|_2}$$
  где $\mathbf{u}, \mathbf{v}$ — векторизованные координаты скелетов.

- **Взвешенное расстояние с маской уверенности:**
  $$\text{Weighted Distance} = \frac{1}{\sum c_i} \sum_{i=1}^{K} c_i \cdot \|\mathbf{u}_i - \mathbf{v}_i\|_1, \quad c_i = \min(c_i^{\text{ref}}, c_i^{\text{user}})$$

## 6. Валидация и проведённые эксперименты

### Сравнение моделей детекции поз
В ходе разработки проведены эксперименты по выбору базовой архитектуры:

| Модель | Число точек | Скорость (FPS) | Точность на наклонах | Выбор |
|---|---|---|---|---|
| TorchVision Keypoint R-CNN (ResNet-50 FPN) | 17 (COCO) | ~8–12 FPS | Средняя при перекрытиях | Базовый baseline |
| **MediaPipe Pose Landmarker (Full Task)** | **33 точки** | **~25–40 FPS** | **Высокая (устойчив к ракурсам)** | **Основная модель** |

### Анализ результатов на тестовом упражнении
- **Среднее косинусное сходство:** **89.87%** (косинус 0.928).
- **Среднее взвешенное расстояние:** **1.921**.
- **Средняя достоверность ключевых точек:** **0.928**.
- На фазах покоя и начала движения сходство превышает **95%**; на фазах глубоких наклонов и скручиваний фиксируется закономерное снижение до **70–75%**, что подтверждает чувствительность алгоритма к отклонениям от техники.

## 8. Установка и запуск

### 1. Подготовка окружения
```powershell
py -3.11 -m venv .venv
.venv\Scripts\Activate.ps1
python -m pip install --upgrade pip
pip install -r requirements.txt
pip install -e .
```

### 2. Запуск пайплайна
Поместите по одному видеофайлу формата `.mp4` в папки `data/original/` и `data/reference/`, затем выполните:
```powershell
python scripts/main.py
```

### 3. Запуск тестов
```powershell
python -m unittest discover tests/
```

---

## 9. Выходные данные

После выполнения скрипта в папке `output/` формируются:
1. `morning_coach_result.mp4` — видео с side-by-side сравнением поз, цветовой индикацией скелета и панелью обратной связи.
2. `morning_coach_metrics.csv` — датафрейм со столбцами:
   - `alignment_id` — индекс сопоставленной пары;
   - `reference_frame`, `user_frame` — оригинальные номера кадров;
   - `cosine_similarity`, `weighted_distance`, `confidence`, `similarity_percent`.
3. `metrics_plot.png` — графики динамики сходства (%) и взвешенного расстояния по всем кадрам тренировки.
